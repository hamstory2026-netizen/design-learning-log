# design-learning-log

我想學：日常韓文對話。

我以前卡在：沒有一段完整的時間可以學，常常學到一半就放棄。這次想每天學一點點，慢慢累積。

我現在的程度，以及我怎麼測的：韓文字都會念，但有些咬字不夠清楚；單字背得不多，句子懂一些。高中學過一點，大學也修過韓文通識，但之後就沒有再進步。測的方法：開始前請 AI 出 30 個日常單字，看我認得幾個；再朗讀 10 句日常短句，請 AI 檢查有幾句咬字不清楚。

5 週後我要做到：能不看稿說出 20 句日常短句（打招呼、自我介紹、點餐、聊喜好）；看一段 TXT、TWS 或 ILLIT 的綜藝片段，不看字幕能聽懂 5 句常用句子的意思；再測一次 30 個單字，認得的數量比第一次多。

我練習的場景、時間和每週次數：通勤時間和空閒時間，每天都練，每次大約 20 分鐘，一週 7 次。

那個時候我有空的感官：眼睛、耳朵、手都可以。

我的產品會怎麼幫我：從日常對話開始學。網頁會從 TOMORROW X TOGETHER、TWS、ILLIT 的綜藝節目和訪談挑片段，整理出裡面的單字和句子，並附上中文（或英文）對照，才不會太難。每次的份量大約 20 分鐘，通勤時打開就能直接練。
